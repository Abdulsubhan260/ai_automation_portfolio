# Petalnex AI Automation Internship Portfolio

Welcome to my official GitHub portfolio for the **6-Week AI Automation Internship Program** at **Petalnex Pvt. Ltd.** 

This repository contains all 30 daily tasks across Weeks 1 to 5, as well as **all 6 completed Final Capstone Projects** for Week 6. Every workflow has been built, tested, and documented locally on self-hosted n8n.

##  Week 6: Final Capstone Projects (All 6 Options Built)

I have fully engineered and deployed all 6 Capstone Project options specified in the internship curriculum:

1.  **[Option 1: AI Customer Support CRM & RAG Automation](./Week-6-Final-Capstone-Project/Option-1-Customer-Support-CRM)**
    *   *Features:* Asynchronous Webhook Intake, Groq Llama 3 Triage, Pinecone RAG Search, Supabase PostgreSQL Logging, and Wait-Node Human Approval.
2.  **[Option 2: AI Recruitment & Applicant Screening Funnel](./Week-6-Final-Capstone-Project/Option-2-Recruitment-Automation)**
    *   *Features:* Resume Skill Extraction, Fit-Score Calculation, Supabase Database Storage, Auto-Rejection Filters, and Human Recruiter Review.
3.  **[Option 3: AI Lead Qualification & B2B Sales Router](./Week-6-Final-Capstone-Project/Option-3-Lead-Qualification)**
    *   *Features:* Agify API Demographic Enrichment, B2B Buying Intent Scoring, Supabase Storage, Sales Manager Wait-Gate, and Automated Nurture Routing.
4.  **[Option 4: Company Knowledge AI Assistant](./Week-6-Final-Capstone-Project/Option-4-Company-Knowledge-RAG)**
    *   *Features:* Pinecone Vector Search (384-dim Hugging Face Embeddings), Simple Memory, Source Citations, and Automatic Database Escalation for unknown queries.
5.  **[Option 5: NoSQL AI Complaint Management System](./Week-6-Final-Capstone-Project/Option-5-Complaint-Management-MongoDB)**
    *   *Features:* Unique MongoDB Ticket ID Generation (`TCK-<id>`), Sentiment & Legal Risk Detection, NoSQL Document Updates, Emergency Manager Review, and Departmental Switch Routing.
6.  **[Option 6: Automated AI Management Reporting](./Week-6-Final-Capstone-Project/Option-6-Management-Reporting)**
    *   *Features:* Weekly KPI Aggregation, JavaScript `.reduce()` Calculations, Llama 3 Executive Anomaly Analysis, Structured Output JSON Parsing, and Gmail Report Delivery.
